Initial release of svelte-audio-ui. This changeset establishes the baseline
for all future versioning.

- Audio Provider with context-based architecture
- Audio Player with composable controls
- Audio Queue with shuffle, repeat, and insert modes
- Audio Track display with cover art and metadata
- Audio Playback Speed control
- UI components: Fader, Knob, Slider, Sortable List, XY Pad
- Particles: Player Widget, Pocket Synth, Wave Shaper
- Registry system for CLI installation via shadcn-svelte
